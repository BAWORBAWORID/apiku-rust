API Key & Authentication GUIDE

Status-Based Access

Endpoint yang berstatus premium atau vip memerlukan API key. Key premium bisa akses endpoint premium, key VIP bisa akses semua.

Endpoint Restrictions

API key bisa di-restrict ke endpoint tertentu saja menggunakan allowedEndpoints. Contoh: /api/am/* hanya bisa akses endpoint AM.

Rate Limits

Setiap key memiliki rate limit: maxPerDay (per hari) dan maxPerMinute (per menit). Set 0 = unlimited.

Cara Menggunakan API Key

?apikey=YOUR_KEY X-API-Key: YOUR_KEY Authorization: Bearer YOUR_KEY
