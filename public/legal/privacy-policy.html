Kebijakan Privasi 📜

Terakhir diperbarui:

01

Pendahuluan

Zyyvor API ("kami", "milik kami", atau "Layanan") berkomitmen untuk melindungi privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, mengungkapkan, dan melindungi informasi Anda saat menggunakan layanan REST API kami yang terdiri dari lebih dari 500++ endpoint yang mencakup AI chat, downloader, tools, maker, dan berbagai kategori lainnya.

02

Informasi yang Dikumpulkan

2.1 Informasi yang Dikumpulkan Secara Otomatis

Saat Anda menggunakan Layanan, kami secara otomatis mengumpulkan informasi tertentu:

  • Alamat IP untuk pembatasan rate limit, keamanan, dan deteksi spam
  • Metode request (GET/POST), path endpoint, dan waktu respons
  • User-Agent string dari header HTTP
  • Timestamp dari setiap request API
  • Log error dan informasi debugging
  • Jumlah request per hari untuk setiap IP (statistik agregat)

2.2 API Key

Beberapa endpoint premium memerlukan API Key yang dikirim melalui header X-API-Key, query parameter, atau Bearer token. API Key hanya digunakan untuk autentikasi akses dan tidak dibagikan ke pihak ketiga.

03

Penggunaan Informasi

Kami menggunakan informasi yang dikumpulkan untuk tujuan berikut:

  • Menyediakan, memelihara, dan meningkatkan Layanan
  • Memantau dan menganalisis pola penggunaan secara agregat
  • Mendeteksi, mencegah, dan mengatasi masalah teknis
  • Menerapkan rate limiting, anti-DDoS, dan mencegah penyalahgunaan
  • Menjalankan sistem keamanan otomatis (SSRF protection, bot shield, IP ban)
  • Mengirim notifikasi Telegram ke admin saat terjadi pelanggaran rate limit
  • Menampilkan statistik penggunaan secara publik (tanpa data pribadi)
  • Mematuhi kewajiban hukum yang berlaku
  • Menjaga keamanan dan integritas Layanan
04

Penyimpanan dan Retensi Data

Kami menyimpan data log dan informasi request untuk periode yang wajar sesuai kebutuhan operasional Layanan. Berikut detail retensi data:

  • File Upload (v1/v2) — Disimpan di server lokal, dihapus otomatis setelah 5 menit
  • File Upload V3 — Diunggah ke CDN pihak ketiga, masa simpan dikonfigurasi saat upload (menit/jam/hari/minggu/bulan). File dan metadata otomatis dihapus saat kedaluwarsa
  • Request Logs — Disimpan dalam database statistik sebagai data agregat (tanpa konten request)
  • Session Admin — Berlaku selama 24 jam, dihapus otomatis
  • Data Banned IP — Disimpan permanen sampai dihapus manual oleh admin
  • Live Feed Notifikasi — Dihapus otomatis setelah 24 jam, direset bulanan

Data pribadi tidak disimpan di luar yang diperlukan untuk operasional Layanan.

05

Pembagian Data

Kami tidak menjual, memperdagangkan, atau menyewakan informasi Anda kepada pihak ketiga. Kami hanya dapat membagikan informasi dalam keadaan berikut:

  • Notifikasi Telegram berisi informasi minimal (alamat IP, jumlah pelanggaran) dikirim ke admin saat pelanggaran rate limit
  • File yang diupload dapat diakses publik melalui URL unik atau CDN pihak ketiga (untuk Upload V3)
  • Untuk mematuhi kewajiban hukum atau perintah pengadilan
  • Untuk melindungi hak, privasi, keamanan, atau properti kami
  • Untuk mencegah atau menyelidiki pelanggaran Ketentuan Layanan
  • Dengan persetujuan eksplisit dari Anda
06

Keamanan

Kami menerapkan langkah-langkah keamanan yang wajar untuk melindungi informasi Anda:

  • Rate Limiting — Batas request per hari per IP, pelanggaran berulang diban secara permanen
  • Global Lock — Sistem otomatis mengunci akses jika mendeteksi lebih dari 100 IP unik dalam 2 menit (anti-DDoS)
  • SSRF Protection — Validasi terpusat memblokir URL yang mengarah ke IP privat (10.x, 192.168.x, 127.x), DNS rebinding, dan protokol berbahaya (file://, gopher://)
  • Bot Shield — Firewall cerdas memblokir request dari scanner, probe, dan bot berbahaya
  • IP Ban System — IP yang melanggar batas rate limit akan diban permanen dengan notifikasi Telegram
  • Path Traversal Protection — Perlindungan terhadap akses file di luar direktori yang diizinkan
  • Enkripsi Transmisi — Semua komunikasi menggunakan HTTPS/SSL via Cloudflare

Namun, tidak ada metode transmisi melalui Internet atau penyimpanan elektronik yang 100% aman.

07

Cookies dan Tracking

Layanan API ini tidak menggunakan cookies atau teknologi pelacakan untuk pengguna umum. Kami hanya mengandalkan identifikasi berbasis IP untuk keperluan rate limiting dan keamanan.

Namun, Admin Dashboard menggunakan session cookies (apiku.sid) yang bersifat httpOnly dan kedaluwarsa dalam 24 jam untuk menjaga keamanan sesi admin. Session ini tidak digunakan untuk pelacakan pengguna biasa.

08

Hak Pengguna

Anda memiliki hak untuk:

  • Mengakses data pribadi yang kami simpan tentang Anda
  • Meminta penghapusan data pribadi dan/atau file yang telah diupload
  • Meminta penghapusan alamat IP dari sistem pencatatan
  • Menolak pemrosesan data tertentu
  • Mengajukan keluhan terkait penggunaan data Anda

Untuk pertanyaan lebih lanjut atau permintaan terkait data, hubungi kami melalui Telegram @ZyyvorAPI.
